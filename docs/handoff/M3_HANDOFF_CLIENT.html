NPP Lite Scoring History Transition UX

1) What was completed

  • NPP Lite — a 10-question, mobile-first assessment (one question per screen, scale 1–5). Progress is shown (e.g. 3 / 10). Back and Next / Finish are full-width buttons for easy tapping.
  • Scoring and storage — answers are scored server-side (reverse items, domain averages, derived composites, bands, internal profile key). Each completion is saved as a new row in your history (retakes never overwrite previous results).
  • After the 5-day program — when Day 5 is completed, the app shows a short transition screen that explains the next step and points clearly to NPP Lite.
  • Dashboard — when all five days are done, the main button stays directional (“Continue your training”) and leads into that transition flow instead of feeling like a dead end.
  • Retake NPP — from the dashboard, users can start the assessment again; each run adds another history entry.

2) What to review (recommended walkthrough)

  • Sign in → Dashboard → start or continue the 5-day program as before.
  • Complete Day 5 → you should land on the program completion screen → tap Continue to NPP Lite → answer all 10 questions → Assessment saved.
  • From Dashboard: Retake NPP → complete the assessment again (to validate repeat completions when you review data with the team).
  • With all five days complete: Dashboard primary button should read Continue your training and open the transition screen.

Note: The three-screen results experience (profile name, domain bars, strengths/focus) is planned for Milestone 4. M3 focuses on capture, scoring, and history.
