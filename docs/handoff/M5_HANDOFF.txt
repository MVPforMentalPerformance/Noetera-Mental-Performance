Milestone 5 — Handoff Package

Status: Milestone 5 is complete. The MVP is feature-complete and deployed.
Live URL: https://mvp-for-mental-performance-app.vercel.app

1) Short summary (what was completed in Milestone 5)

- Full 5-day program is live end-to-end:
  - All 5 audio sessions converted (WAV → 160 kbps MP3) and served from /public/audio/program/.
  - Audio player (native HTML5) integrated on each day page via a day → URL config layer (src/config/audio.ts).
  - Tap-based reflection choices (3 per day) stored as JSONB in program_day_progress.reflection_payload.
  - Sequential unlock: each completed day opens the next. Day 5 completion routes to /program/complete.
- Profile page updated to show real user data from Supabase Auth (email-derived initials and display name).
- Program overview (/program) now shows day titles (Stabilize, Thought detachment, etc.) alongside day numbers.
- Day metadata (titles, blurbs, reflection options) extracted to a shared module (src/lib/program/meta.ts).
- Unit test suite added (Vitest, 11 tests covering scoring engine: profile key thresholds, tie-breaking, reverse scoring, full scoreNppLite pipeline).
- `npm test` wired to `vitest run`.

2) What to review (client-facing)

- Sign up → lands on /dashboard.

- App unlocks Day 2 and navigates to /program/day/2 automatically.
- Repeat through Day 5 → lands on /program/complete with NPP Lite CTA.
- Take NPP Lite (/assessment) → view results (/insights, 3-step wizard).

Secondary:
- /program: verify all 5 day rows show titles and correct status (completed / current / locked).
- /profile: verify initials and display name match the logged-in account.

4) Data + behavior notes

- Audio: files are served as static Next.js public assets; no CDN or signed URL required in MVP.
  To swap to hosted URLs: update src/config/audio.ts values — no component changes needed.
- Program unlock: user_profiles.program_max_unlocked_day is the single source of truth (1–5).
  completeDayAction in src/app/(app)/program/_actions.ts advances it after each completion.
- Reflections: stored in program_day_progress.reflection_payload as { choice: string }.
- Tests: run with `npm test`; covers pure-function scoring logic (no Supabase mocking needed).

5) Source of truth (where things live)

- Shared day metadata:          src/lib/program/meta.ts
- Audio URL config:             src/config/audio.ts
- Day page (audio + reflection): src/app/(app)/program/day/[day]/page.tsx
- Program completion action:    src/app/(app)/program/_actions.ts

6) Deployment

- Platform: Vercel (auto-deploy on push to main branch).
- Environment variables required (set in Vercel dashboard):
    NEXT_PUBLIC_SUPABASE_URL        — Supabase project URL
    NEXT_PUBLIC_SUPABASE_ANON_KEY   — Supabase anon key
- No vercel.json required — Next.js is detected automatically.
- .env.local for local development (excluded from git via .gitignore).
