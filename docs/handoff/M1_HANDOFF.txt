3) Database schema (simple explanation + access rules)
We created 3 main data areas:

A) User profile & program unlock
- Stores which program day the user is allowed to access (days 1–5).

B) Program progress (days 1–5)
- Stores whether each day is unlocked/completed and saves the user’s reflection answers for that day.

C) Assessment results (NPP Lite)
- Stores results as history: every retake creates a new saved result with a timestamp (nothing is overwritten).

Access rules
- The database is configured so each user can only see and change their own data.
