2. Running tests

Unit tests (Vitest)

npm test

11 tests, pure TypeScript, no Supabase dependency. Test file: src/lib/scoring/__tests__/npp-lite.test.ts. Covers scoring thresholds, tie-breaking order, reverse-score application, full pipeline with both array and object input formats, and error paths.

3. Audio architecture

Current setup (static files)

Files live in public/audio/program/ and are served by Next.js as /audio/program/day-N.mp3. The URL layer (src/config/audio.ts) maps day index → URL string.

Migrating to hosted / CDN URLs

Update the values in src/config/audio.ts to absolute URLs. No component changes needed — the day page reads the URL directly from PROGRAM_AUDIO_URLS[day].

4. Program unlock logic

Source of truthColumnSemantics
user_profiles program_max_unlocked_day Integer 1–5. Day N is accessible iff day_index ≤ program_max_unlocked_day.
program_day_progress completed_at, reflection_payload Set by completeDayAction in src/app/(app)/program/_actions.ts. Advances program_max_unlocked_day to min(5, day + 1).

5. Deployment

Vercel (production)

Auto-deploys on push to main. No vercel.json required.

Required env vars (set in Vercel dashboard):

NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY

Local development

cp .env.example .env.local   # fill in Supabase URL + anon key
npm install
npm run dev                  # http://localhost:3000
npm test                     # run unit tests
