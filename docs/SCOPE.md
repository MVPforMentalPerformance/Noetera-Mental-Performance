# NOETERA MVP — locked scope

Source: Developer Handoff + client agreements.

## In scope for MVP

### Authentication

- Email/password sign-up and sign-in
- Session handling
- Forgot password
- No heavy account settings

### 5-day Mental Clarity program (free entry)

- Days 1–5 with fixed themes (Stabilise → … → Calm performance)
- Each day: short copy (2–4 lines), 3–5 min audio, **tap-only reflection** (lightweight options — no journaling or long-form text in MVP), “Mark complete”
- Days unlock strictly in order
- Clear states: completed / current / locked
- After day 5 — CTA to the NOETERA Performance Profile (NPP Lite)

### NPP Lite (10 items)

- 5 domains × 2 questions: Focus & Attention, Thought Control, Emotional Regulation, Action & Consistency, Performance State
- Scale 1–5 (Almost never → Almost always)
- Reverse-scored items: **Q2, Q4, Q6, Q8**

### Scoring

- Domain score = average of its two items
- Derived “strengths”: Mental Toughness (Thought+Emotion), Flow (Focus+Performance), Self-Concept (Performance+Action), Life Effectiveness (Action+Emotion)
- Bands: 4.2–5.0 Strong, 3.2–4.1 Developing, 2.0–3.1 Needs Training
- Logic centralized (auditable + testable)

### Results (3 screens)

1. Profile with one of: Aware but Inconsistent, Driven but Overloaded, Capable but Distracted, Underconfident Performer + short paragraph
2. Domain breakdown (bars + short insight per domain)
3. Top 2 strengths, top 2 growth areas, brief guidance

### Dashboard (home after sign-in)

- Welcome
- **Primary CTA:** 5-day program — **Start Day 1** (new) or **Continue** (in progress); this is the main entry point for new users
- Profile card (from latest NPP) — secondary to the program CTA
- Day 1–5 progress
- Option to retake NPP (new history row) — secondary (e.g. text link)
